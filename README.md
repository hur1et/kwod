# KEEP WORKING OR DIE

Project sources, tests, deployment scripts and documentation are in
[`keep-working-or-die/`](keep-working-or-die/README.md).

The workspace handoff is in [`HANDOFF.md`](HANDOFF.md). Project reports and final
deliverables are included alongside the code. Local environments, browser
profiles, runtime databases and generated deployment archives are excluded.

Run development commands from `keep-working-or-die/`; see its README and deployment
documentation for setup and operation.
